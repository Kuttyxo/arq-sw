COLISEO OS — Modulo de Cristobal (servicios profe + notif)
============================================================

CONTENIDO DE LA CARPETA
-----------------------
  soa_lib.py                   Libreria del profesor (sin modificar)
  servicios/soa_service_profe.py   Servicio 'profe' (crear, listar, asistencia, clases_profe)
  servicios/soa_service_notif.py   Servicio 'notif' (enviar, listar_pendientes)
  clientes/cliente_profe.py    Menu interactivo del perfil Profesor
  data/profesores.json         Persistencia de profesores (inicia vacio: [])
  data/notificaciones.json     Persistencia de notificaciones (inicia vacio: [])
  prueba_local.py              Script de prueba automatica (no se entrega, es para ti)


REQUISITOS
----------
- Docker corriendo.
- Python 3 (probado con 3.11).


PASO 1 — Levantar el BUS del profesor
-------------------------------------
  docker run -d --name soabus -p 5000:5000 jrgiadach/soabus:v1
  docker ps                  # confirmar que esta "Up" y mapea 0.0.0.0:5000

Para detenerlo despues:
  docker stop soabus && docker rm soabus


PASO 2 — Levantar los servicios (2 terminales, desde esta carpeta)
------------------------------------------------------------------
  Terminal A:
    python3 servicios/soa_service_profe.py
    # esperado: Servicio 'profe' registrado: b'...sinitprofe'

  Terminal B:
    python3 servicios/soa_service_notif.py
    # esperado: Servicio 'notif' registrado: b'...sinitnotif'

Dejalas corriendo. Si las cierras se desregistran del BUS.

NOTAS TECNICAS
--------------
- soa_lib.py es la copia del profesor. No tocar.
- Los servicios llaman al BUS en localhost:5000. Si cambias el host
  del BUS, tendras que ajustar connect_to_bus en soa_lib.py.
- El BUS responde con prefijo <5-largo><5-nombreservicio><OK><payload>.
  El snippet 'data[5:]' del documento del curso deja "OK" pegado al
  JSON y rompe json.loads. Por eso en este codigo se quita tambien
  el prefijo "OK" antes de parsear.
- 'asistencia' necesita una accion 'reservas_por_clase' en el servicio
  'reser'. Hay que coordinarlo con Benjamin (no esta en la tabla del
  documento).
